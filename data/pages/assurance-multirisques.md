Description du produit
Par ce contrat, AGC S.A vous propose une couverture généralement complète de vos biens et responsabilités encourues. Suivant votre activité, nous vous proposons :
• Les Risques industriels,
• Les Multirisques PME/PMI,
• Les multirisques bureaux,
• Les multirisques commerces,
• Les Multirisques Habitation.
Dans ces contrats, nous vous proposons suivant les spécificités de vos risques :
• L’incendie,
• Le Vol,
• Les Dégâts des eaux,
• Les Bris de Glaces,
• Les Risques informatiques,
• Les Bris de machine,
• Les Perte d’Exploitation (après Bris de machine et/ou après Incendie),
• Arrêt de froid.
Note : Chacune de ces garanties peut faire l’objet d’un contrat à part entière.
Le saviez-vous ?
A partir de 5000 FCFA seulement il est possible de vous assurer à hauteur de 250 000 FCFA , ce pour une durée d’un an contre tout accident corporel susceptible de vous arriver au quotidien.
